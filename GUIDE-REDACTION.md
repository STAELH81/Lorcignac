# Lorcignac - guide de rédaction

Chaque rubrique dispose de son fichier HTML à la racine.

- Écris tes contenus à la place des éléments entre crochets.
- Conserve les liens du menu pour circuler entre les pages.
- Modifie style.css pour l'apparence générale.
- Ajoute tes images dans un dossier images/ lorsque tu en auras.
- Les fichiers PDF pourront être ajoutés dans un dossier documents/.
- Aucune histoire ni indice d'ARG n'est introduit dans ces squelettes.
- La page fiction.html indique clairement que la commune est fictive; complète les mentions de publication avant mise en ligne.
- Le code postal 81230 est un code réel du secteur de Lacaune, utilisé uniquement pour le décor fictif.
- Les formulaires, coordonnées et liens externes restent volontairement non fonctionnels tant que tu ne les as pas décidés.
