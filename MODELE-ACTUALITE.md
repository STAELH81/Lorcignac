# Modèle d'actualité - Lorcignac

Copier le bloc suivant dans `actualites.html`, à l'intérieur de `<main>`, avant `</main>`.

Changer uniquement la date, le titre et le paragraphe. Chaque nouveau bloc devient une actualité distincte.

```html
<div class="entree">
  <strong>JJ-MM-AAAA</strong>
  <h3>[Titre de l'actualité]</h3>
  <p>
    [Texte de l'actualité]
  </p>
</div>
```

Pour plusieurs paragraphes dans la même actualité :

```html
<div class="entree">
  <strong>JJ-MM-AAAA</strong>
  <h3>[Titre de l'actualité]</h3>
  <p>
    [Premier paragraphe]
  </p>
  <p>
    [Deuxième paragraphe]
  </p>
</div>
```

Rappel : la date de dernière mise à jour du site est le 22/09/2005. Les textes existants sont écrits par l'auteur. Le modèle n'ajoute aucun événement au scénario.
