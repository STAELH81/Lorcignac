# Les Amis de la Forêt - site indépendant

Prototype visuel inspiré des sites associatifs français de 2015 à 2018.
L'association est présentée comme existant depuis une période antérieure (2007), sans inventer son histoire.

Ce site est préparé dans `amis-de-la-foret/` pour éviter de créer un nouveau dépôt sans concertation.
Son contenu et son style sont indépendants du site municipal de Lorcignac.

Pour voir le site, ouvrir `index.html` avec un serveur local.
Les textes entre crochets sont réservés à l'auteur. Aucun événement ni mystère n'a été ajouté.

Pour un hébergement séparé, choisir ce dossier comme répertoire de publication ou déplacer les fichiers dans un dépôt distinct.
Le lien vers Lorcignac (`../index.html`) devra alors être remplacé par son adresse publique.
