# Bulletins municipaux

Les PDF de 2003, 2004 et 2005 sont des maquettes vierges.

Pour changer les textes, modifier les fichiers HTML dans `modeles/`, puis les ouvrir dans un navigateur et utiliser `Ctrl+P > Enregistrer au format PDF`.

Remplacer ensuite le PDF de l'annee correspondante dans ce dossier.

Le bulletin 2005 est une edition de septembre : le site est fige au 22/09/2005.
