# PixelPoche v1.3

Utilitaire fonctionnel dans le navigateur : sélection ou glisser-déposer de JPG/PNG/WebP, réduction proportionnelle (320 à 1600 px ou original), export JPEG/PNG/WebP, rotation, réglage de qualité, prévisualisation, téléchargement et comparaison des tailles.

Toutes les conversions restent locales, sans requêtes serveur. La largeur limite s'applique avant rotation. Le navigateur peut ne pas supporter certains formats et peut renvoyer un JPEG comme format de repli.

L'histoire ARG n'est pas définie ici : un emplacement existe en bas de la page « À propos », mais aucun secret n'a été inventé.
