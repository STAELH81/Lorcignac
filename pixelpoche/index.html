Mode d'emploi

  1. Cliquez sur « Choisir un fichier » pour sélectionner votre photo.
  2. Choisissez 800 pixels pour une utilisation sur les forums.
  3. Réglez la qualité puis cliquez sur « Réduire ma photo ! ».
  4. Enregistrez le fichier et conservez votre original.

Conseil : le JPEG convient aux photographies. Le PNG est utile pour les dessins, les textes et les images transparentes. Les pixels transparents deviennent blancs en JPEG.

À propos

PixelPoche a été fait pour les gens qui veulent envoyer leurs photos sans passer la soirée à chercher le bon réglage. Aucun fichier n'est envoyé sur un serveur.
